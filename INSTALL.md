# Установка сторонних приложений на ГУ со штатной прошивкой

На ГУ со штатной прошивкой APK ставится со смартфона: на ГУ включается отладка в инженерном
меню, а смартфон подключается к нему как компьютер. Модифицированная прошивка и DSp для этого
не нужны. Способ проверен на Haval Dargo.

На прошивке GWM-club кабель и инженерное меню не нужны: APK ставится прямо на ГУ, см.
[инструкцию для GWM-club](INSTALL-CLUB.md).

Понадобятся:
- смартфон на Android с приложением
  [Bugjaeger Mobile ADB](https://play.google.com/store/apps/details?id=eu.sisik.hackendebug);
- APK, заранее скачанный на смартфон;
- переходник USB-OTG и кабель USB-A — USB-A.

## 1. Включить отладку на ГУ

1. Откройте на ГУ «Настройки системы» → «Системная информация».
2. Несколько раз нажмите на строку «Версия ПО» и введите первый пароль: `*#4435ab`.

   <img src="install/1-version.png" width="720" alt="Настройки системы → Системная информация → Версия ПО">

3. Откроется Engineer Menu. В разделе Software Information несколько раз нажмите на строку
   HW Version и введите второй пароль: `aZ10&*+30`.

   <img src="install/2-hw-version.png" width="720" alt="Engineer Menu → Software Information → HW Version">

4. Пролистайте список разделов слева до конца, откройте Others и в строке USB mode выберите
   `peripheral`. Из инженерного меню не выходите.

   <img src="install/3-usb-peripheral.png" width="720" alt="Others → USB mode → peripheral">

В инженерном меню много настроек ГУ. Не меняйте те, назначение которых вам неизвестно.

## 2. Установить APK

1. Подключите смартфон к левому USB-разъёму ГУ через переходник OTG и кабель USB-A — USB-A.
   На смартфоне включите режим OTG, если он есть в настройках.
2. Запустите Bugjaeger. Он должен показать подключение `gwmv3`. Если его нет, выключите и снова
   включите отладку на ГУ или переподключите кабель.
3. На вкладке приложений нажмите «+» и выберите APK.
4. После установки верните на ГУ USB mode `host`.

## После установки

Откройте установленное приложение на ГУ хотя бы раз: многие приложения без первого запуска
не запускаются вместе с ГУ.

Новая версия ставится тем же способом поверх старой, настройки сохраняются.

# Приложения для головных устройств GWM

Здесь лежат описания небольших приложений для ГУ Tank и Haval на платформе Aptiv с Android 9,
а готовые APK — в разделе [Releases](https://github.com/theKomix/gwm-apps/releases).

| Приложение | Что делает |
|---|---|
| [Яркость день/ночь](dimmer/README.md) | Отдельная яркость экранов днём и ночью, переключается по автосвету |
| [TBOX: только Wi-Fi](tboxrules/README.md) | Интернет для приложений на ГУ — только через Wi-Fi, трафик сим-карты TBOX не тратится |
| [GWM Comfort](comfort/README.md) | Сценарии комфорта: по запуску двигателя, дню и ночи, пассажиру включает подогрев, обогрев и меняет яркость, в том числе днём и ночью |

## Общее для всех

Требования к ГУ и прошивке у каждого приложения свои — они на странице приложения, вместе с
машинами, на которых его проверяли.

Приложения устанавливаются так же, как любые другие на вашем ГУ, а новая версия ставится
поверх старой. Как поставить приложение без модифицированной прошивки и DSp, описано
[в инструкции](INSTALL.md).

Релизы помечены именем приложения: `dimmer-v3.5` — «Яркость день/ночь» 3.5,
`tboxrules-v0.1.0` — «TBOX: только Wi-Fi» 0.1.0, `comfort-v0.6` — «GWM Comfort» 0.6.
